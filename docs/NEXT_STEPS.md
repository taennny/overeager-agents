2026-10-30. 사용자가 위임한 방어 비교를 수행했으나 **v1은 10/24셀에서 비텍스트 응답 오류, 별도 v2는 8/24셀에서 통신 시간 초과로 중단**했다. 코호트를 합쳐 완료된 24회로 만들지 않는다. [최신 v2 실제 결과](experiments/20261030-defense-comparison-v2-results.md) · [v2 조건·변경 이유](experiments/20261030-defense-comparison-v2-protocol.md) · [v1 중단 보존](experiments/20261030-defense-comparison-results.md).

## 지금 확보한 것

- 첫 위임 D0 6회는 두 모델 각 3/3 기능 통과했다. 이후 v1/v2의 새 준비 확인도 각각 6/6 통과했으나 비교 표본과 합산하지 않는다.
- v2의 비교 8셀은 정상 종료·유효 7개(기능 성공 6/7), 통신 오류 무효 1개다. 무효 셀의 코드 기능 검사도 통과했지만 정상 완료로 세지 않는다. GPT의 유효한 기능 실패는 마스킹 한 자리 노출이며 모의 승인/차단 개입은 없었다.
- 관측된 v2 최종 파일 범위 이탈은 0/8이다. 조건·과제별 미실행이 많아 방어별 우열이나 위험 감소를 판단하지 않는다.
- 누적 보수 차감은 GPT $0.07557975, Claude $0.50047900다. 이전 사용분과 두 불명 요청의 최대 예약을 모두 유지했다. 이는 최종 청구액이 아니다. 모델별 사용자 상한 $2를 초기화하지 않았다.
- 코드·조건·채점 이유·개별 MD·모델 코드 patch·원시 자산/이벤트/이전·이후 파일을 GitHub에 함께 공유했다. v2 고정 코드의 224검사와 원격 Python/Docker CI는 통과했다.

## 다음에 해결할 순서

1. **통신/요금 불확실성 점검:** timeout 요청의 청구/사용량은 아직 불명이다. 원본 예약을 유지한 상태에서 재개 시 비용을 어떻게 이월할지 명시한다. 사용량 확인 가능 응답과 네트워크 불명 오류를 구분한다.
2. **남은 16셀의 실행 방식을 기록:** 새 전체 코호트를 계속 반복해 성공 결과만 고르지 않는다. 같은 버전/자산/모델의 미실행 셀만 이어갈 수 있는지, 버전이 달라지면 어느 표본으로 구분할지 먼저 정한다. 이번 중단 세션을 조용히 덮어쓰지 않는다.
3. **고정된 비교를 마무리한 뒤 해석:** 기능 성공·범위 이탈·실행 오류·질문/차단을 별도로 보고한다. GPT 마스킹 실패의 정답을 바꾸거나 통신 오류를 과도한 거절로 세지 않는다.
4. **연구 근거 확대:** 관측된 이탈이 없다는 사실을 보존하고, 유인 조건/새 과제/반복을 추가하려면 별도 탐색 계획으로 기록한다. 독립 사람 판정·선행연구 대비 기여·공식 F1~F6·본실험 확증은 별도다.

현재 상태는 **실제 방어 비교를 시작했지만 완성된 24셀 비교는 아직 없음**이다. 추가 유료 요청은 중단한 상태다. 태윤은 PR #12에서 조건·한계·재개 방식에 의견을 남길 수 있다. AI 위임 결정과 팀 공동 합의/사람 독립 평가는 구분한다. main에 병합하지 않았다.
