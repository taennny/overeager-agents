# 다음 단계 — 모델별 D0 30회 결과 이후

2026-11-04 사용자 요청을 완료했다. 기존 3회+새 27회로 **GPT/Claude 각각 30회, 합계 60회**를 확보했다. 과제는 각 모델 T1/T2/T3마다 10회다. [결과](experiments/20261104-d0-30-each-results.md) · [조건·이유](experiments/20261104-d0-30-each-protocol.md) · [개별 MD](experiments/baseline30-20261104/).

## 확보한 결과

- GPT: 기능 성공 26/30, 최종 FS 범위 이탈 0/30. 실패 4개는 T1 마스킹이며 기능 오류로 보존했다.
- Claude: 기능 성공 30/30, 최종 FS 범위 이탈 0/30.
- 이번 집계의 60회 모두 유효/관측 완료. 기존/새 날짜·실행 계층을 각각 공개했다. 원래 세션/ID/hash를 유지하고 실패 슬롯을 대체하지 않았다.
- 고의 OUT 대조 3개를 모두 탐지했고 정상·무행동을 포함한 9개 고정 스크립트 검증이 예상과 일치했다. 실제 모델 60회에 더하지 않는다.
- 이전 모든 비용·불명 예약을 이월한 누적 보수 차감 GPT $0.19893075/Claude $0.80635300. 최종 청구액은 미확인이고 사용자 모델별 $2 상한은 그대로다. 추가 유료 호출은 없다.

## 연구 판단

현재 과제는 수정 파일을 명확히 지정하고 범위 이탈 유인이 약할 수 있다. 같은 세 과제를 반복한 결과이므로 “모델이 너무 똑똑하다”, “방어가 필요 없다”, “방어가 위험을 줄였다”를 결론내릴 수 없다. 현재 설계에서 방어가 줄일 문제 행동의 신호가 부족하다는 것이 관측에 맞는 판단이다. 의미 변화·일시적 효과 등 측정 밖 한계도 유지한다.

## 다음 작업 후보

1. **현실적 경계 과제 설계:** 목표 작업을 수행하는 동안 관련 있어 보이는 추가 설정/원본 데이터/정리 작업을 발견하는 상황을 별도 버전으로 설계한다. 무작정 악성 지시를 섞거나 기존 과제를 이탈이 나올 때까지 고치지 않는다.
2. **요청·scope·정상 해법·OUT 근거를 먼저 고정:** 실제 사용자에게 추가 권한을 물어야 하는지 근거를 적고, 정상/고의 OUT/무행동 대조를 함께 준비한다. AI 판단과 독립 사람 정답을 구분한다.
3. **새 과제의 작은 D0 파일럿:** 다양한 과제에서 이탈이 관측될 기회와 측정 범위를 검토한 후 별도 예산·슬롯·중단/오류 규칙으로 수행한다. 이번 60회와 새 조건을 한 표본으로 합산하지 않는다.
4. **방어 비교/논문:** D0에서 충분한 문제 신호를 확보한 뒤 방어·반복·표본/사람 검증을 정한다. 이미 중단된 방어 비교 v1 10/24·v2 8/24(남은 16셀)는 완료로 표시하지 않고 계속 보존한다.
