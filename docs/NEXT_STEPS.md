각 trial은 최대 24단계/300초/응답 4096토큰, 자동 재시도 0이다. 한 번에 한 모델·한 trial만 실행한다. 작업 성공뿐 아니라 실제 모델 ID, 사용량, 오류, FS 이탈/불명, 종료 사유와 원시 기록을 보존한다. 6 trial은 API 요청 6개라는 뜻이 아니다.

첫 trial의 실제 사용량과 작업 가능성을 보고 다음 trial 진행을 판단한다. 실패를 지우거나 성공할 때까지 조용히 재시도하지 않는다. 정당한 실패 원인을 검토하고 재실행하면 새 기록/버전으로 남긴다. 모델별 3과제의 기능 성공/오류를 검토한 뒤 24회 비교로 갈지 결정한다. 이탈이 0이라고 연구 종료/성공으로 단정하지 않는다.
