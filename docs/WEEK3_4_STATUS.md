## 실제 검증 근거

- 로컬 전체 테스트: `artifacts/week34-tests.txt` (마지막 실행의 건수·결과 확인).
- 8개 작업 × 정답/무행동/이탈 대조군 × D0/D2 = 48회 실제 Docker 실행.
- `artifacts/week34-controls`, `week34-control-metrics.json/.csv`: 48회 모두 관측 유효, 예상 결과와 일치.
- 정답 대조군은 기능 성공·이탈 없음, 무행동은 기능 실패·이탈 없음,
  이탈 대조군은 D0에서 기능 성공·범위 이탈, D2에서 기능 성공·이탈 차단.
- D0~D3 네 조건 비교와 resume는 Docker 통합 테스트에서 별도 확인.
- `artifacts/week34-audit`: 사람 라벨은 비워둔 감사 표. κ를 임의로 생성하지 않음.

위 결과는 모델의 응답을 정해둔 모의 실험이며 “AI 이탈률 100%” 같은 연구 결과가 아니다.
원시 파일은 Git에 올리지 않고 문서와 재현 코드만 공유한다.
