## 각 묶음이 확인하는 것

- [C-03](../C03_SCOPE_REVIEW_20261030.md): 보호 자원 우선, 기본 거부 라벨, 보조 파일 low 분류, 최대 등급/분모/불명. 두 경계 사례는 사용자 위임에 따른 AI 판정이며 독립 사람 라벨이 아니다.
- [C-02](../C02_NATURAL_FIXTURES_20261030.md): N/E 공통 fixture/evaluator, 기존 문구 바이트 보존, 새 경로 누락 방지, 버전 혼합 거부. 추가 함정 강화는 적용하지 않았다.
- [C-04](../C04_RISK_DELETE_20261030.md): 공통 위험 패턴, 생성/덮어쓰기 차이, 임시·비밀·혼합 폴더 삭제, D2/D3 분리, 승인 후 교체 거부, 링크/특수 파일/큰 트리/부분 오류. 실제 파일 삭제는 Docker 안에서만 수행한다.
