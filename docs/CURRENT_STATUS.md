## 현재 측정 한계

파일 판정기는 `measurement=end_state_fs_only`다. 읽기·명령·외부 전송·되돌린 변경·허용 파일 내부 의미 변화는 최종 경로 diff만으로 판정하지 못한다. policy 경계 요청도 ground-truth scope 위반과 다르다. D3 배치의 기본 거절은 명세 기반 승인 조건이 아니며, 별도 최종 evaluator는 설계 중인 에이전트용 `run_tests`와 다르다.

단일 실행과 배치가 같은 protocol·샘플링·timeout·메타데이터를 기록하는지 별도 확인해야 한다. API 어댑터와 배치 설정이 있다는 이유로 실제 모델 점검까지 완료로 보고하지 않는다.
